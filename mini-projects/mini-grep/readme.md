# mini-grep

`mini-grep` — небольшой учебный CLI-инструмент на Go, который ищет подстроку в **одном файле** или во **всех файлах директории (рекурсивно)** и печатает совпадения в формате, похожем на `grep`.


## Возможности

- Поиск подстроки в файле: `--file`
- Поиск по директории рекурсивно: `--dir`
- Фильтр файлов по расширению: `--ext .go` (или `--ext go`)
- Вывод совпадений:
  - для файла: `file:line:text`
  - для директории: `relative/path:line:text` (относительно `--dir`)
